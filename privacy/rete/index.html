プライバシーポリシー

最終更新日: 2026年10月28日

Life Hack Tools（以下「当団体」）は、Rete（以下「本アプリ」）における利用者の個人情報の取り扱いについて、以下のとおりプライバシーポリシーを定めます。本アプリは、店舗（オーナー）と来店者（お客様）の双方が利用するスタンプカード・特典管理アプリです。利用者の役割によって取り扱うデータが異なります。

01収集する情報

本アプリでは、以下の情報を取り扱います。

  • 店舗アカウント情報: 店舗オーナーは、メールアドレスとパスワードでアカウントを作成・サインインします。来店者（お客様）はアカウント登録不要で、端末上で自動生成される匿名IDで利用できます。
  • ユーザーが入力・登録する情報: アプリの機能に必要なデータ（店舗名、スタンプカードや特典の設定内容、テキスト、数値、日時など）
  • 画像: 店舗オーナーが、スタンプや特典の画像として端末の写真ライブラリから選択した画像。選択した画像はクラウドストレージ（Supabase Storage）にアップロードされ、アプリ内での表示に使用されます。
  • カメラ: 店舗QRコードや特典用QRコードの読み取りにカメラを使用します。読み取りはQRコードの解析のみを目的とし、写真の撮影・保存は行いません。
  • 自動生成される識別子: アプリ内で生成される匿名ID（特定の個人を識別するものではありません）。データの同期・引き継ぎに使用します。
  • プッシュ通知の情報（来店者が通知を許可した場合のみ）: プッシュトークン、端末の種類（iOS／Android）、アプリの表示言語、端末のタイムゾーンなど。詳しくは「05 プッシュ通知」をご覧ください。
  • 有料プランの契約情報（有料プランを申し込んだ店舗のみ）: Stripe の顧客ID・サブスクリプションID、契約の状態、店舗の国など。カード番号などの支払い情報は当団体では受け取りません。詳しくは「06 店舗向け有料プランのお支払い（Stripe）」をご覧ください。
  • 診断情報: クラッシュログおよびパフォーマンスデータ（アプリの安定性向上のため。診断ツールの設定状況により取得される場合があります）。

来店者（お客様）について、本アプリは氏名・電話番号などの個人を特定できる情報や、位置情報を収集しません。店舗アカウントについては、サインインのためにメールアドレスを収集します。

※ 本アプリには将来的な店舗位置表示機能のための設定が一部含まれていますが、現在のバージョンでは位置情報の取得・利用は行っていません。位置情報を取得する機能を追加する場合は、本ポリシーを更新したうえで、利用者の許可を得て取得します。プッシュ通知のために保存するタイムゾーン（例: Asia/Tokyo）は、通知を送る時間帯を決めるためだけに使い、位置情報としては扱いません。

02取り扱うデータの一覧

本アプリが取り扱うデータの種別・用途・第三者共有・暗号化の有無は以下のとおりです。利用者のデータを第三者に販売することはありません。機能の提供のために外部サービスへ渡すものは、下の表の「第三者共有」の欄と「04 第三者サービスの利用」に記載しています。通信はすべて暗号化（HTTPS / TLS）されます。

取り扱うデータ種別 対象 用途 第三者共有 暗号化
メールアドレス 店舗アカウント 店舗オーナーのサインイン・認証 なし 転送時あり
画像 店舗が選択 スタンプ・特典画像の登録・表示 なし 転送時あり
カメラ映像 全利用者 QRコードの読み取り（保存なし） なし —
匿名ID 全利用者 データの同期・引き継ぎ なし 転送時あり
プッシュトークン・端末の種類・言語・タイムゾーン 通知を許可した来店者 店舗からの特典・お知らせのプッシュ通知 Expo・Apple（APNs）・Google（FCM）に通知の配信のためだけに渡します 転送時あり

03情報の利用目的

収集した情報は、以下の目的にのみ使用します。

  • アプリの機能提供および動作に必要な処理（スタンプカード・特典の発行・利用など）
  • 店舗アカウントの認証
  • 端末間のデータ同期・引き継ぎ
  • 来店したことのある店舗からの特典・お知らせのプッシュ通知（来店者が通知を許可した場合のみ）
  • 店舗向け有料プランの申し込み・請求・解約の処理と、契約の状態に応じたプランの切り替え
  • アプリの品質向上・不具合の改善

プッシュ通知の情報や契約情報を、広告の配信に使うことはありません。

04第三者サービスの利用

本アプリは、機能の提供のために以下の外部サービスを利用します。

  • Supabase: バックエンド処理（認証・データの保存・画像の保存）に利用します。店舗のメールアドレス、登録データ、アップロード画像、匿名ID、プッシュ通知の情報、有料プランの契約情報はこのサービス上で安全に管理されます。
  • Expo（Expo Push Service）: プッシュ通知の配信に利用します。プッシュトークンと通知の内容（店舗名、お知らせの題名、特典の内容など）を Expo に送ります。
  • Apple Push Notification service（APNs）／ Firebase Cloud Messaging（FCM、Google）: Expo から iOS 端末へは Apple の APNs、Android 端末へは Google の FCM を通じて通知が届けられます。
  • Stripe: 店舗向け有料プランの決済・請求・解約の手続きに利用します。日本以外の店舗では Stripe の Managed Payments を利用し、販売者は Link（Stripe）となります。
  • Sentry: クラッシュ解析・品質改善のため、診断情報の収集に利用する場合があります。

これらは本アプリの機能提供に必要な範囲でのみ利用されます。当団体が利用者の情報を第三者に販売することはありません。

05プッシュ通知

本アプリ（バージョン 1.1.2 以降）は、来店者（お客様）が通知を許可した場合に限り、来店したことのある店舗からの特典やお知らせをプッシュ通知でお届けします。通知の許可は、初回起動時ではなく、スタンプを受け取った後の画面でご案内します。

  • 保存する情報: Expo のプッシュトークン（端末に通知を届けるための宛先）、端末の種類（iOS／Android）、アプリの表示言語（日本語／英語／ベトナム語）、端末のタイムゾーン、インストールごとの識別子から作ったハッシュ値。これらは匿名IDに結びつけて保存します。あわせて、店舗ごとの通知のオン・オフの設定と、通知の送信記録（通知の種類・送信日時・送信結果）を保存します。
  • 通知の内容: 誕生月の特典のご案内（誕生月を登録している場合）、おかえりクーポンのお知らせ、あと1回のスタンプで特典がもらえることのご案内（店舗が有効にした場合）、店舗からのお知らせ（店舗が通知でも送ると選んだ場合）。送るのは、スタンプカードをお持ちの店舗からの通知だけです。1つの店舗から送る数には月ごとの上限があり、端末のタイムゾーンで夜間（21時〜翌9時）には送りません。
  • 渡す先: 通知を届けるため、プッシュトークンと通知の内容を Expo のプッシュ通知サービスに送り、Expo から Apple の APNs（iOS）または Google の FCM（Android）を通じて端末に届けます。店舗には送信数の合計だけを表示し、プッシュトークンなどの端末の情報は店舗に開示しません。
  • 止め方: 端末の設定で本アプリの通知をオフにすると、すべての通知が届かなくなります。店舗ごとに止めたい場合は、アプリの店舗のページで、その店舗からの通知をオフにできます。
  • 削除: アプリを削除するなどして端末が通知を受け取れなくなったことを Expo から知らされた場合、その端末のプッシュトークン等を自動的に削除します。同じ端末でアプリを入れ直した場合は、古い登録を新しいものに置き換えます。これらの情報や送信記録の削除を希望される場合は、下記のお問い合わせ先までご連絡ください。

06店舗向け有料プランのお支払い（Stripe）

店舗向けの有料プランのお申し込み・お支払いは、Stripe が提供する決済サービスで行います。

  • 支払い情報: カード番号などの支払い情報は、Stripe の決済画面（Stripe Checkout）やカスタマーポータルで店舗が直接入力し、Stripe が取り扱います。当団体はカード番号などを受け取らず、保存もしません。
  • 日本以外の店舗: Stripe の Managed Payments で決済し、販売者は Link（Stripe）となります。この場合、お支払い・税・領収書に関わる情報は Link（Stripe）が取り扱います。
  • 当団体が保存する情報: Stripe の顧客ID・サブスクリプションID・料金プラン（価格）のID・申し込み手続きのID、契約の状態（有効・支払いの再試行中・解約済みなど）、現在の請求期間の終了日と解約の予約の有無、店舗の国（国コード）、Stripe から届いた通知の受信記録（イベントのIDと種類）。
  • Stripe に渡す情報: 申し込みの際に、店舗を識別するID、店舗の国、表示言語を Stripe に渡します。メールアドレスなどの請求に必要な情報は、Stripe の画面で店舗が直接入力します。
  • 削除: 解約やカードの変更は、料金ページからカスタマーポータルで行えます。店舗アカウントの削除をご希望の場合は、下記のお問い合わせ先までご連絡ください。有料プランを解約したうえで、当団体が保存する上記の情報を削除します。Stripe（Link）が保存する支払いの記録は、Stripe（Link）が自らのプライバシーポリシーと法令に基づいて取り扱います。

07情報の保存

設定値などの一部のデータは端末内のローカルストレージに保存されます。店舗アカウント情報、登録データ、アップロード画像、プッシュ通知の情報、有料プランの契約情報はクラウドサーバー（Supabase）に保存されます。

08第三者提供

当団体は、利用者の情報を第三者に提供、販売、共有することはありません。ただし、法令に基づく場合と、「04 第三者サービスの利用」に記載した外部サービスに、機能の提供に必要な範囲で取り扱いを任せる場合を除きます。

09データの削除

利用者は、アプリを端末からアンインストールすることでローカルデータを削除できます。プッシュ通知の情報は「05 プッシュ通知」に記載のとおり自動的に削除される場合があります。店舗アカウントやサーバー上のデータの削除を希望される場合は、下記のお問い合わせ先までご連絡ください。

10お子様のプライバシー

本アプリは、13歳未満のお子様を対象としておらず、意図的にお子様の個人情報を収集することはありません。

11ポリシーの変更

当団体は、必要に応じて本ポリシーを変更することがあります。変更があった場合は、本ページにて公開します。
