JA EN VI

プライバシーポリシー

最終更新日: 2026年10月22日

Life Hack Tools（以下「当団体」）は、Yane（同居の割り勘と家事当番／以下「本アプリ」）における利用者の情報の取り扱いについて、以下のとおりプライバシーポリシーを定めます。本アプリは、ルームシェア・同棲・シェアハウスで暮らす人が、お金と家事の記録を共有し、連絡を取り合うためのアプリです。アカウント登録は不要です。家のデータを閲覧・編集できるのは同じ家のメンバーだけで、当団体は利用者の情報を販売しません。任意の外部通知で共有する範囲は08項に記載します。本アプリは広告を表示しません。

01アカウントと識別子

本アプリはアカウント登録を必要としません。起動時に、Google が提供する Firebase Authentication の匿名認証によって、端末ごとの識別子を作成します。この識別子は、利用者がどの家のメンバーであるかを判別するために使います。また、家プランの購入を管理するための、匿名のユーザー ID としても使います（16項）。

メールアドレス、電話番号、氏名の入力を求めることはありません。Apple、Google、LINE または Zalo のアカウントとの連携は任意です（次項）。

02アカウントの連携（任意）

本アプリは、登録なしでも使えます。希望する場合は、Apple、Google、LINE または Zalo のアカウントと連携できます（iPhone では Apple・Google・LINE・Zalo、Android では Google・LINE・Zalo。Zalo はベトナム国内からの利用時のみ）。連携すると、機種変更やアプリの入れ直しのあとも、同じ家と記録に戻れます。

LINE との連携には、LY Corporation が提供する「LINE ログイン」（OpenID Connect）を使い、認証は Google の Firebase Authentication（Identity Platform）を通して行います。

Zalo との連携には、Zalo Group（VNG Corporation）が提供する Zalo のログインを使います。Zalo のログインで得た認可コードを、当団体の中継サーバー（Google Cloud Run・東京リージョン）が Zalo に渡し、利用者の Zalo の ID を確認します。Zalo は ID をベトナム国内の IP アドレスからの問い合わせにしか返さないため、この確認の通信は、利用者の端末を経由して Zalo に届きます（中継サーバーと Zalo の間の通信は暗号化されており、端末で中身を見ることはできません）。確認した ID をもとに、Firebase Authentication でサインインします。中継サーバーは Zalo の ID を保存しません。

Zalo でのログインのボタンを表示するかどうかを決めるため、ログインや連携の画面を開いたときに、同じ仕組みで Zalo に届くかどうか（ベトナム国内からの利用かどうか）を確かめます。このとき、Zalo の ID は受け取りません。また、位置情報は使いません。

連携したときに受け取る情報は、以下のとおりです。これらは Firebase Authentication に保存します。

  • Apple、Google、LINE または Zalo が発行する、利用者の識別子
  • Apple または Google から提供されるメールアドレス（Apple の「メールを非公開」を選んだ場合は、中継用のアドレス）
  • LINE の表示名（LINE と連携した場合）

LINE からは、メールアドレスを受け取りません（メールアドレスの取得の権限を申請していません）。

Zalo からは、Zalo の ID だけを受け取ります。表示名、メールアドレス、電話番号、写真は受け取りません。

メールアドレスと LINE の表示名は同居人に表示しません。また、連絡や広告には使いません。

03保存する情報

本アプリは、家のメンバーで共有するために、利用者が入力した以下の情報を保存します。

  • 家と同居人: 家の名前と通貨、同居人の表示名と色。表示名は利用者が付ける呼び名で、実名である必要はありません。
  • お金の記録: 立替の記録（題名・金額・日付・支払った人・分担）、その変更履歴、精算の記録。
  • 家事の当番: 家事の名前・間隔・順番・完了の記録。
  • 共有の日用品: 共有の日用品の在庫と、買い出しリスト。
  • コメントと家の連絡: 記録（立替・家事・在庫・精算）に付けるコメントと、家のメンバー全員が見る「家の連絡」の本文、投稿した人、投稿した日時（05項）。
  • 写真: コメントや「家の連絡」に付けた写真（04項）。
  • 「Yane が伝える」: 送ったお知らせと、依頼の記録（06項）。
  • 通報: 利用者が送った通報（07項）。
  • 通知の登録: プッシュ通知を受け取るための端末の登録（08項）。
  • 招待と参加: 招待コードと、家への参加の申請（機種変更の際に、同居人の枠を新しい端末へ付け替える申請を含みます）。
  • 家プラン: 家プランの期限と状態、払っている人、お試しの期限、家ごとの利用量（写真の枚数などの件数）。これらは、当団体のサーバーが書き込みます（16項）。

04写真

本アプリでは、利用者が選んだ写真や撮影した写真を、コメントや「家の連絡」に付けられます。写真ライブラリやカメラは、利用者が写真を付ける操作をしたときにだけ使います。

  • 写真は送る前に端末の中で、長辺 1600 ピクセルの JPEG に縮小します。その際、撮影場所などの位置情報を含む EXIF（撮影情報）を取り除きます。
  • 縮小した写真は、Google が提供する Firebase Storage（東京リージョン）に保存します。
  • 写真を見られるのは、その家に在籍しているメンバーだけです。
  • 利用者が写真を付けた投稿を削除しても、写真は記録として保存したままになります（コメントや「家の連絡」には表示されなくなります）。写真は、家が解散したとき（最後の参加者がアカウントを削除したとき）に、家ごと削除します。

05コメントと家の連絡

本アプリでは、家のメンバー全員が見る掲示板「家の連絡」と、記録（立替・家事・在庫・精算）へのコメントを書けます。本文は Cloud Firestore に保存します。

  • 投稿を削除すると本文は消え、その場所には「削除されました」という行が残ります。
  • 家を出た人やアカウントを削除した人の投稿も、家の記録として残ります。家が解散すると、家ごと削除します。

06「Yane が伝える」

「Yane が伝える」は、用意された文面を、依頼した人の名前を出さずに、Yane からのお知らせとして家のメンバー全員に送る機能です。家のメンバーには、誰が依頼したかは表示されません。

ただし、嫌がらせなどの悪用を調べるため、誰が依頼したかを、運営だけが見られる記録として残します。

07通報

コメントや「家の連絡」を通報すると、以下の内容が運営に届きます。運営への知らせは、当団体が社内の連絡に使っている Slack の、関係者だけが見られるチャンネルに送ります。

  • 通報の理由
  • 通報された投稿（本文と、写真の有無）
  • 投稿した人と通報した人の、家の中での ID
  • 家の ID

同居人の表示名や家の名前は、運営への知らせに含めません。運営は、通報への対応に必要な範囲で、通報された投稿とその写真を確認することがあります。

08通知

通知を許可した場合、同じ家のメンバーが「家の連絡」やコメントを書いたときや、「Yane が伝える」のお知らせがあったときに、プッシュ通知を送ります。そのために、端末ごとに以下の情報を Cloud Firestore に保存します。この情報を読めるのは、本人と、通知を送る当団体のサーバーだけです。

  • 端末の通知用トークン
  • 表示言語（通知の文面に使います）
  • 通知の種類ごとの受け取り設定
  • その端末で非表示にしている同居人の ID（その人からの通知は送りません）

通知は、Expo の通知サービスを経由して、Apple または Google の通知サービスから端末に届きます。通知の文面には、家の名前、投稿した人の表示名、本文の一部が含まれます。通知の許可は、端末の設定からいつでも取り消せます。

家事の当番のお知らせは、これまでどおり端末の中だけで予約するローカル通知です。

任意のLINEグループ通知

LINE連携を利用できる版では、家のオーナーが送信先グループを確認し、種類ごとに同意した場合に限り、LINEへ通知します。LINEログインとは別の任意機能です。家の連絡の新着、Yaneからの連絡、指定タイムゾーンの毎朝9時の家事まとめについて、一般的なお知らせと公開アプリURLだけを送ります。投稿本文・写真・名前・金額・家やメンバーのID・Yaneに頼んだ人は通知に含めません。

LINEグループには本アプリを使っていない人も参加でき、すべての参加者が通知を読めます。接続のため、グループ内に投稿されたメッセージをWebhookで一時的に処理し、接続コードを判定します。受信した投稿本文は保存しません。

当団体のサーバーは、送信先グループのID・名前・人数、接続したオーナーと在籍の世代、通知の種類・言語・タイムゾーン、配信処理の結果と予約通数を保存します。接続コードはハッシュだけを保存し、10分で失効します。短期コード・Webhookの重複防止や回数制限の記録、無効化後の接続情報は期限を設けて削除対象にします（コード10分、その他2日）。配信予約・元イベントの重複防止記録は作成から30日後に削除対象にします。期限後の実際の削除には処理の遅れがあります。

接続状態は家の在籍メンバーが確認でき、オーナーがアプリから解除できます。接続したオーナーの退出や家の削除後は、在籍と接続世代の再確認で新たな送信を止めます。切断直前に送信中だった要求は取り消せない場合があります。すでにLINEへ送った文面は、解除やアカウント削除ではLINE上から消えません。

09クラッシュ報告

不具合を見つけて直すため、Sentry にアプリのエラーの情報を送ります。送るのは、エラーの内容、発生した画面や処理、端末の機種、OS とアプリのバージョンなどです。また、動作の速さを確かめるため、一部の処理にかかった時間を送ることがあります。

立替の題名、同居人の表示名、コメントなど、利用者が入力した内容は送らない設定にしています。Sentry のデータは米国で保存されます。

10保存場所と外部のサービス

家のデータは Cloud Firestore に、写真は Firebase Storage に保存します。どちらも Google が提供するサービスで、保存先のリージョンは東京（asia-northeast1）、本アプリ専用のプロジェクトを使っています。通知の送信、通報の受け付け、「Yane が伝える」、Zalo でのログインの確認、解散した家の削除、利用状況の集計（12項）、家プランの購読の反映と利用量の数え直し（16項）は、Google Cloud Run 上の当団体のサーバーで行います。

本アプリは、以下の事業者のサービスを利用しており、サービスの提供に必要な範囲で、情報の取り扱いを委託しています。

  • Google: Firebase（Authentication・Cloud Firestore・Storage）、Cloud Run、Google でのサインイン、Android の通知サービス、Google Play の決済
  • Apple: Apple でサインイン、iPhone の通知サービス、App Store の決済
  • LY Corporation: LINE ログイン、任意のLINEグループ通知（Messaging API）
  • Zalo（VNG Corporation）: Zalo でのログイン
  • RevenueCat, Inc.（米国）: アプリ内課金の購入の管理（16項）
  • Expo: プッシュ通知の中継
  • Sentry: エラーの報告
  • Slack: 通報の運営への連絡

11情報を閲覧できる人

家のデータ（コメント、「家の連絡」、写真を含みます）を本アプリで閲覧・編集できるのは、同じ家に在籍しているメンバーだけです。この制限は、Cloud Firestore と Firebase Storage のセキュリティルールによって行っています。家を出たメンバーは、その家のデータを見られなくなります。

当団体は利用者の情報を販売しません。08項の任意のLINE通知では、オーナーが確認した送信先グループへ、同意した種類のお知らせを提供します。本アプリは広告を表示しません。

12サービス改善のための集計

当団体は、サービスの改善と料金プランの設計のため、家ごとのメンバー数・記録や写真の件数などを、家や個人を特定できない形で集計することがあります。集計の結果には、家の名前・表示名・記録の内容は含みません。

13利用しないもの

本アプリは、以下のものを利用していません。

  • 外部の分析ツール（12項の集計は、当団体のサーバー内で行います。RevenueCat は、購入の管理のためだけに使います（16項））
  • 広告 SDK

また、位置情報、連絡先（アドレス帳）、マイクは使いません。写真ライブラリとカメラは、利用者が写真を付けるときにだけ使います（04項）。

14端末に保存する情報

本アプリは、お使いの端末に以下の情報を保存します。

  • 表示言語の設定
  • ログイン状態（匿名認証、または連携したアカウントでのサインイン）
  • 通知の種類ごとの受け取り設定と、非表示にしている同居人の ID
  • 家事のお知らせの予約
  • 家プランの購入の状態（RevenueCat の SDK が保存します）

15アカウントとデータの削除

各タブの左上にある家の名前を押して「家」の画面を開き、「アカウント」を開きます。画面の一番下の「削除」にある「削除する」を押し、確認で「削除する」を押すと、アカウントを削除できます。どの家に参加していても、以下は削除されます。

  • 本アプリのアカウント（Firebase Authentication のユーザー）。Apple、Google、LINE または Zalo のアカウントと連携している場合は、その結び付きも削除されます。Apple と連携している場合は、Apple 側のサインインの許可も取り消します。
  • 参加しているすべての家での在籍
  • 端末に保存していた設定と、家事のお知らせ

参加しているそれぞれの家のデータは、以下のように扱います。

  • ほかに同居人が参加している家: あなたは家を出て、家の中でのあなたの名前は消え、「退会した人」と表示されます。立替・精算・家事の記録は、同居人の残高が変わらないよう、家に残ります。あなたが書いたコメントや「家の連絡」、付けた写真も家に残ります。これらの記録での名前も「退会した人」となり、あなたと結び付く情報は残りません。
  • 参加しているのがあなただけの家: 家ごと、記録・コメント・「家の連絡」・写真もすべて削除されます。アプリを入れていない「名前だけの同居人」は、参加している人に数えません。削除はサーバーで行い、おおむね1時間以内に完了します。その家の招待コードは、アカウントを削除した時点で使えなくなり、名前だけの同居人も、あとから参加することはできなくなります。

家プランを購入している場合: アカウントを削除しても、App Store または Google Play の購読は自動では止まりません。購読の管理から解約してください（16項）。あなたが払っていた家は、払った期間の終わりまで家プランのままです。購読を付けていた家とお試しの記録（16項）は、アカウントの削除のあと、おおむね1日以内にサーバーで削除します。ストアと RevenueCat には、購入の記録が取引の記録として残ります。RevenueCat の記録の削除を希望する場合は、下記のお問い合わせフォームからご連絡ください。

アプリを削除してしまった場合や、アプリを開けない場合は、下記のお問い合わせフォームから「アカウント削除の依頼」とお送りください。受け付けから30日以内に対応します。アカウントを特定するため、連携した Apple または Google のアカウントのメールアドレスをご記入ください。LINE と連携している場合は、その旨と LINE の表示名をご記入ください。Zalo と連携している場合は、その旨をご記入ください。

詳しくは「アカウントの削除」のページをご覧ください。

16アプリ内課金（家プラン）

本アプリには、家ごとのサブスクリプション「家プラン」があります。家のメンバーの1人が App Store または Google Play で購入すると、その家のメンバー全員が使えます。記録すること、全員で共有すること、データを書き出すことは、家プランが無くても使えます。

決済は Apple または Google が行います。当団体が、クレジットカードなどの支払いの情報を受け取ることはありません。支払いの情報は、Apple または Google のプライバシーポリシーに従って取り扱われます。

購入の管理には、RevenueCat, Inc.（米国）のサービスを使います。RevenueCat に渡すのは、以下の情報だけです。氏名、メールアドレスや電話番号などの連絡先、家の記録の内容は渡しません。RevenueCat のデータは米国で保存されます。

  • 本アプリが付けた匿名のユーザー ID（01項の識別子）
  • 購入の履歴（商品、購入日、期限、ストアの取引 ID）
  • 端末の OS とアプリのバージョンなど、購入の処理に必要な情報

RevenueCat での取り扱いは、RevenueCat のプライバシーポリシーをご覧ください。

当団体のサーバー（Google Cloud Run）は、購入の直後と、購読の状態が変わったときに、RevenueCat から購読の状態を受け取り、家のデータに以下を書き込みます。これらは、家のメンバー全員が見られます。

  • 家プランの期限と状態（自動で更新されるか、解約済みか、支払いに問題があるかなど）、商品とストアの種類
  • 払っている人（家の中でのメンバーの枠）。払っている人の表示名は、家のメンバーに表示されます（「○○さんが払っています」）。
  • お試しの期限

また、運営だけが見られる記録として、以下をサーバーに保存します。

  • 購読を付けている家と、付けた日時（1つの購読を付けられる家は1軒で、別の家への付け替えは30日に1回までです）
  • お試しを使った家と、お試しを始めた時点の家のオーナーの識別子（家を作り直してお試しを繰り返すことを防ぐため）。この記録は、家が解散しても残し、その人がアカウントを削除したときに削除します。
  • RevenueCat からの知らせを処理した記録（種類と受け取った日時。90日後に削除します）

お試し: 家ごとに1回、30日間、家プランを無料で試せます。お試しは当団体のサーバーが家に付けるもので、ストアでの購入やクレジットカードの登録は要りません。期限が来ても、自動で有料にはなりません。

利用量: 無料で使える範囲を判定するため、当団体のサーバーが、家ごとに写真の枚数、「Yane が伝える」の回数、繰り返しの立替の件数などを数え、家のデータに保存します。保存するのは件数だけです。

解約: 家プランの解約は、App Store または Google Play の購読の管理から行います。本アプリのアカウントを削除しても、ストアの購読は自動では止まりません。払っている人が家を出たり、アカウントを削除したりした場合、その家は払った期間の終わりまで家プランのままで、次の更新では延びません。ストアの購読は続くため、不要であれば解約してください。
