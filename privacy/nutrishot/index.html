プライバシーポリシー

最終更新日: 2026年10月23日

Life Hack Tools は、食事写真から栄養素を推定・記録する NutriShot における情報の取り扱いを以下のとおり説明します。アカウント登録は不要です。

01写真の送信と同意

撮影・選択した食事の写真1枚を、料理名・推定重量・タンパク質・脂質・炭水化物・kcalを推定するため Google の Gemini API に送信します。写真を送信する前にアプリ内で同意を求めます。同意しない場合は解析しません。設定の「AI 解析への同意」から取り消すと、次の解析前に再び同意を求めます。取り消しは今後の送信を止めるもので、既に処理された写真をGoogleから削除する操作ではありません。

02端末内の食事記録

保存操作を行った食事の写真のコピー、料理名、量、PFC、kcal、記録日時、目標値、同意状態などの設定を端末内に保存します。食事履歴を当団体のクラウドに同期する機能はありません。端末のOSによるバックアップはOSの設定・提供者の条件に従います。

03解析サービスと不正利用対策

Firebase を用いる解析サービスでは、写真を当団体が管理する Google Cloud Functions を経由して Gemini に渡します。写真と推定結果を食事履歴としてサーバーに保存せず、当団体が追加するログにも写真・推定内容・証明トークンを記録しません。通信に伴うIPアドレスや時刻等がクラウド提供者のアクセスログで処理されることがあります。日別の呼び出し件数をFirestoreに保存して利用上限を管理しますが、そこに写真や利用者IDは含めません。旧バージョンではGoogle APIへ直接送信する場合があります。

04アプリ・端末の証明

不正利用防止のため Firebase App Check を使用するバージョンでは、端末・アプリの証明情報をGoogleまたはAppleの証明サービスへ送り、解析リクエストに証明トークンを添付します。再送防止に使われたトークンは、Firebase側で最大30日保持されます。詳細は Firebaseのプライバシー情報 をご覧ください。

05外部サービスでの写真の処理

送信された写真と応答はGoogleのサービス条件に基づいて処理されます。Google側での安全性確認等の保持については Gemini APIの追加利用規約 と Googleのプライバシーポリシー をご確認ください。人物、個人情報、機密情報が写る写真は送信しないでください。

06購入と更新配信

購入はApp StoreまたはGoogle Playが処理し、当団体がカード番号を受け取ることはありません。購入・復元・利用権限の管理のためRevenueCatへ、匿名のアプリ内ID、購入履歴・レシートまたは購入トークン、端末・OS等の技術情報を送ります。食事写真や栄養記録はRevenueCatに送りません。RevenueCatのプライバシーポリシーをご覧ください。更新確認のため、OS・アプリ情報とランダムなインストール識別情報をExpo（EAS Update）へ送ります。食事記録は更新リクエストに含めません。Expoのプライバシーポリシーをご覧ください。

07権限と広告

カメラは食事の静止画撮影に使用します。写真の選択にはシステムピッカーを使います。録音やアルバムへの保存は行いません。広告SDK、広告目的の追跡、食事内容の第三者への販売はありません。解析・不正利用防止・購入管理・更新配信に必要な外部処理は上記のとおりです。

08削除と問い合わせ

保存した食事はアプリ内で削除できます。アプリが保存した写真のコピーも削除しますが、写真ライブラリの元画像は削除しません。端末内のアプリデータはアプリの削除により消去できます。AI同意の取り消しやアプリの削除はサブスクリプションの解約にはなりません。解約はストアで行ってください。外部サービス側の情報に関するご相談を含め、お問い合わせフォームからご連絡ください。食事写真を添付する必要はありません。

09推定値とポリシーの変更

栄養値は写真に基づく推定で、実測値と異なる場合があります。量を確認・補正してご利用ください。本アプリは医療機器ではなく、診断や治療のためのものではありません。情報の取り扱いに変更がある場合はこのページを更新し、送信内容や目的に重要な変更がある場合はアプリ内の案内・同意も更新します。
