プライバシーポリシー

施行日: 2026年9月11日 / 最終更新日: 2026年9月29日

Life Hack Tools（以下「当団体」）は、Batto（草野球スコアブック／以下「本アプリ」）における利用者の情報の取り扱いについて、以下のとおりプライバシーポリシーを定めます。本アプリはアカウント登録やログインを必要とせず、起動時に端末ごとの匿名の識別子を自動で作成してご利用いただけます。試合・チーム・予定の記録は、まずお使いの端末内に保存され、通信状況に応じて当団体の Firebase（Google Cloud Firestore）のサーバーへ自動的に送信されます。このほか、不具合の検出と修正、動作の改善のために、クラッシュログと動作速度の計測データを収集します。また、利用者が「設定・サポート」画面からフィードバックを送信したときは、その内容と、調査に必要なアプリ・端末の情報を受け取ります。本アプリは広告を表示せず、広告目的のトラッキングも行いません。

01端末とサーバーに保存される情報（試合・チーム・予定）

本アプリは、起動時に端末ごとの匿名の識別子を自動で作成します。ログイン画面はありません。以下の情報は、まずお使いの端末内に保存され、通信状況に応じて当団体の Firebase（Google Cloud Firestore・東京リージョン、プロジェクト名 batto-lht）のサーバーへ自動的に送信されます。アップデート前から端末に残っていたデータは、アップデート後の最初の起動時にまとめてサーバーへ送信されます。

  • 試合の記録: 打席の結果・走者・得点などの記録、打順・守備、両チームのチーム名と選手名、試合の終わり方、試合の日時（保存キー: batto.activeGame.v1 ほか）。
  • チーム情報: チーム名、選手名、背番号、前回の打順・守備（保存キー: batto.teamProfiles.v1）。
  • 予定: 試合予定の日時・対戦相手・場所など、利用者が入力した内容。
  • 匿名の識別子: 端末ごとに自動で作られる ID。

次の情報は、サーバーへは送信せず端末内にのみ保存されます。

  • 記録する人の名前: 最初のご案内（オンボーディング）で入力する、記録する人自身の名前。
  • 通知の予約の識別子: 予定の通知を端末内で管理するためのもの。

これまでの試合: 端末内には最大100試合まで保存されます。サーバーに送信済みの試合は、端末内の一覧から消えてもサーバーから読み戻せます。「これまでの試合」画面から試合を削除すると、サーバー上の記録も削除されます（削除されたことを示す印は残ります。印に試合の中身は含まれません）。

相手チームの記録を取り込んだとき: 相手チームが Batto で共有した試合のリンクを貼ると、その共有に含まれる情報（チーム名、打順の選手名、打席と守備の記録、スコア、試合の日付）を読み込み、利用者の試合の記録の一部として、この端末とサーバー（Firebase）に保存します。取り込んだ記録は、利用者が「外す」を押すか試合を削除するまで残り、相手が共有を取り消しても消えません。取り込んだ記録は、利用者が共有するページには載りません。相手チームのデータを書き換えることはありません。

サーバー上のデータは、その匿名の識別子の持ち主だけが読み書きできるよう、Firebase のセキュリティルールで制限しています。

匿名の識別子は端末内に保存されます（iOS では iCloud バックアップに含まれます）。機種変更などでこの識別子が失われると、アプリからそれまでの記録に入れなくなることがあります。

02サーバー（Firebase）に保存される情報

本アプリが Firebase のサーバーに保存する情報は、01 に記載した試合・チーム・予定の記録と匿名の識別子です。通信はすべて暗号化（HTTPS / TLS）されます。

  • 送信するもの: 試合の記録（打席の結果・走者・得点など）、打順・守備、両チームのチーム名と選手名、試合の終わり方、試合の日時、取り込んだ相手チームの記録（01 参照）、予定（日時・対戦相手・場所など利用者が入力した文字）、匿名の識別子。
  • 送信しないもの: 記録する人の名前（オンボーディングで入力する名前）、通知の予約の識別子。写真・位置情報・連絡先も送信しません。予定の「場所」は利用者が入力した文字であり、位置情報（GPS）ではありません。

サーバー上のデータは、その端末の匿名の識別子と紐づけて保存され、その識別子の持ち主だけが読み書きできます。Firebase のセキュリティルールでこれを制限しています。

03共有リンクで公開される情報

試合を共有すると、その試合に公開用の識別子が発行され、共有リンクはその試合そのものを指します。リンクを開くたびに、そのときの最新の内容が表示されます。試合を記録している間は、共有ページの内容も自動的に読み直されます。同じ試合を何度共有しても、発行されるリンクは同じものです。

本アプリは、閲覧できる相手を限定する仕組み（パスワード、招待制など）を提供していません。URL を知っている人であれば誰でも、共有された内容を閲覧できます。

共有ページには両チームの選手名が表示されます。一方で、記録する人の名前や、予定の場所は共有ページには表示されません。選手名を含むページの URL を渡す相手には、十分ご注意ください。

共有の内容には、どちらのチームを自チームとして記録したか（先攻か後攻か）も含まれます。これは、相手チームがその共有を Batto に取り込むときに先攻・後攻を確かめるためのもので、個人の情報ではありません。共有リンクを受け取った人は、その内容を自分の Batto の試合に取り込めます。取り込まれた写しは、あとから共有を取り消しても、取り込んだ人の手元からは消えません。

共有は、アプリの「共有したスコア」画面からいつでも取り消せます。取り消すと、その共有ページは閲覧できなくなります（試合そのものの記録は削除されません）。以前に発行した共有リンクの写しは Firebase 上に移しており、引き続き閲覧できます。これも、共有した端末の「共有したスコア」画面から取り消せます。共有した端末が無い場合（機種変更・アプリの削除など）は、下記のお問い合わせフォームからご連絡ください。

04クラッシュログと動作速度の計測

本アプリは、アプリの不具合の検出と修正、および動作の改善（品質改善・分析目的）のため、Sentry を通じて以下の診断情報を収集します。

  • クラッシュ・エラーの情報: クラッシュやエラーが発生した際のエラー情報、端末の機種、OS のバージョン、アプリのバージョンなど、Sentry が自動的に収集する診断情報。
  • 動作速度の計測データ: アプリの起動や通信にかかった時間、画面の描画の滞りなど、動作の速さに関する計測データ。すべての計測を送るのではなく、約2割を無作為に選んで送信します。

Sentry は、個人を特定できる情報を送らない設定で利用しています。利用者が入力した試合データや選手名を意図的に送信する実装も行っていません。収集した診断情報を第三者へ販売したり、広告目的で提供したりすることはありません。

05フィードバックの送信時に送信される情報

本アプリの「設定・サポート」画面からは、ご意見・不具合の報告・ご質問・データ削除のご依頼を当団体へ送ることができます。送信ボタンを押したときにだけ、以下の情報が送信されます。

  • ご記入いただいた内容: 種類（ご意見 / 不具合 / 質問 / データ削除の依頼）と本文
  • 返信用のメールアドレス（任意）: 入力した場合にのみ送信されます。返信のためにのみ使用します。
  • アプリと端末の情報: アプリ名、アプリのバージョン・ビルド番号・runtimeVersion、OS（iOS / Android）と OS のバージョン、端末の言語設定、端末の機種名

アプリと端末の情報は、不具合を調査するために自動で添えられます。試合データ・チーム情報・共有したスコアが自動で添えられることはありません（本文に書かれた場合を除きます）。

送信された内容は、当団体が Cloudflare 上で運用する受付窓口（form.lh.tools）を経由して、当団体の Slack の非公開チャンネルに届きます。受信時には、受信日時、送信元の国（IP アドレスをもとに Cloudflare が判定したもの）、Cloudflare のリクエスト ID が添えられます。

送信元の IP アドレスは、短時間に続けて送信できる回数を制限する判定に使います。Slack に届く内容には含まれず、当団体が保存することもありません。

受け取った内容は、お問い合わせへの対応と、本アプリの不具合の調査・改善のためにのみ利用し、対応に必要な期間保管します。第三者へ販売したり、広告目的で提供したりすることはありません。なお、ウェブサイトのお問い合わせフォームでの取り扱いは、Life Hack Tools 共通のプライバシーポリシーをご覧ください。

06収集しない情報

本アプリは、以下の情報を収集しません。

  • 氏名、電話番号などの個人を特定できる情報（メールアドレスは、フィードバックの返信先としてご自身で入力した場合にのみ受け取ります）
  • 写真・カメラの映像
  • 位置情報（予定の「場所」は利用者が入力した文字として保存するものであり、位置情報を取得するものではありません）
  • 連絡先（アドレス帳）

また、本アプリは広告を表示せず、広告目的のトラッキングも行いません。当団体が利用者の情報を第三者へ販売・共有することはありません。

07第三者サービスの利用

本アプリは、機能の提供のために以下の外部サービスを利用します。各サービスの取り扱いは、それぞれの提供者のプライバシーポリシーに従います。

  • Firebase（Google）: 試合・チーム・予定の記録の保存、およびスコア共有機能（共有データの保存、閲覧用ページの提供）に利用します。データは Google Cloud Firestore の東京リージョンに保存されます。
  • Sentry: クラッシュ解析と動作速度の計測（品質改善・分析目的）のため、診断情報の収集に利用します。
  • Cloudflare: フィードバックの受付窓口（form.lh.tools）の運用に利用します。
  • Slack: 受け付けたフィードバックを、当団体の非公開チャンネルで受け取るために利用します。

試合・チーム・予定の記録は、01 に記載のとおり自動的に Firebase のサーバーへ送信されます。

08権限

本アプリは、カメラ、写真ライブラリ、位置情報、連絡先などの機微な端末権限を必要としません。

通知（任意）：試合の予定を入れたとき、前日と当日にお知らせするために通知の許可をお願いすることがあります。通知は端末の中で予約するだけで、予定の内容や通知のための識別子をサーバーに送ることはありません。許可しなくても、ほかの機能はすべて使えます。許可は端末の設定からいつでも取り消せます。

09データの保存と削除

  • 端末内のみのデータ（記録する人の名前・通知の予約など）: 本アプリを端末からアンインストールすることで削除されます。
  • サーバー上のデータ（試合・チーム・予定・共有した試合・匿名の識別子）: 利用者が削除するまで保管します。期限を設けて自動で削除することはありません。本アプリを端末からアンインストールしても削除されません。「これまでの試合」画面から試合を削除すると、サーバー上の記録も削除されます（削除されたことを示す印は残り、この印も利用者が削除するまで同じく保管します）。サーバー上のデータは、アプリの「設定・サポート」画面の「サーバーへの保存」欄にある「サーバーのデータを全部消す」から、いつでも全部削除できます。このとき、サーバーの試合・チーム・予定（取り込んだ相手チームの記録と、削除されたことを示す印を含みます）、共有した試合（共有リンクは見られなくなります）、この端末から共有した以前の共有、および匿名の識別子が削除されます。端末の中のデータは残ります。削除したあとはサーバーへの保存が止まり、「サーバーに保存する」を戻すと、新しい匿名の識別子で改めて保存を始めます（以前の共有リンクは戻りません）。
  • 共有したスコア: アプリの「共有したスコア」画面から取り消すと、共有ページは閲覧できなくなります（試合の記録自体は削除されません）。
  • 取り込んだ相手チームの記録: その試合のスコアブックで「外す」を押すか、試合を削除すると削除されます。「サーバーのデータを全部消す」でもサーバーから削除されます。相手が共有を取り消しても消えません。
  • クラッシュログ・動作速度の計測データ: Sentry のサービス上に保存されます。
  • フィードバック: 当団体の Slack の非公開チャンネルに保存され、対応に必要な期間保管します。

10お子様のプライバシー

本アプリは 18 歳以上の方を対象としており、お子様を対象としていません。当団体が意図的にお子様の個人情報を収集することはありません。

11ポリシーの変更

当団体は、必要に応じて本ポリシーを変更することがあります。変更があった場合は、本ページにて公開します。
