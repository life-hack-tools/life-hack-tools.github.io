プライバシーポリシー

施行日: 2026年9月11日 / 最終更新日: 2026年9月20日

Life Hack Tools（以下「当団体」）は、Batto（草野球スコアブック／以下「本アプリ」）における利用者の情報の取り扱いについて、以下のとおりプライバシーポリシーを定めます。本アプリはアカウント登録やログインを必要とせず、匿名でご利用いただけます。試合の記録はお使いの端末内にのみ保存され、その内容が外部へ送信されるのは利用者が「スコアを共有」を実行したときだけです。ただし、利用者が書き出しを選んだ場合は、試合の記録を CSV / JSON ファイルにして、利用者が選んだ先（ファイルの保存先や他のアプリ）に渡します。このファイルが当団体のサーバーへ送信されることはありません。このほか、不具合の検出と修正、動作の改善のために、クラッシュログと動作速度の計測データを収集します。また、利用者が「設定・サポート」画面からフィードバックを送信したときは、その内容と、調査に必要なアプリ・端末の情報を受け取ります。本アプリは広告を表示せず、広告目的のトラッキングも行いません。

01端末内にのみ保存される情報

以下の情報は、お使いの端末内のストレージにのみ保存されます。これらが自動的に外部へ送信されることはありません。

  • 記録中の試合データ: 進行中の試合の内容（イニング、得点、打席の結果など）を端末内に保存します（保存キー: batto.activeGame.v1）。
  • チーム情報: チーム名、打順、選手名、背番号を端末内に保存します（保存キー: batto.teamProfiles.v1）。
  • これまでの試合: 記録した試合の内容（チーム名、得点、打席の結果など）を、最大100試合まで端末内に保存します。「これまでの試合」画面から1試合ずつ削除できます。
  • 共有したスコアの控え: 共有したスコアの URL、タイトル（チーム名と得点）、共有した日時、および共有を取り消すための鍵を、最大50件まで端末内に保存します。

これらのデータは端末内にのみ存在し、本アプリを端末からアンインストールすると削除されます。

ただし、「これまでの試合」画面で書き出しを選んだ場合は、その試合の記録（選手名を含む）を CSV / JSON ファイルにして、利用者が選んだ先（ファイルの保存先や他のアプリ）に渡します。このファイルが当団体のサーバーへ送信されることはありません。

02「スコアを共有」時に送信される情報

利用者が入力した試合データやチーム情報が外部へ送信されるのは、「スコアを共有」を実行したときだけです。このとき、共有機能の提供に必要な範囲で、以下の情報が Supabase のサーバーへ送信されます。

  • 両チームのチーム名
  • 両チームの得点
  • イニング、および試合の進行状態
  • 試合のタイトル
  • 打順（両チームの選手名の一覧） — 入力内容によっては実名が含まれる場合があります
  • 直近12件の打席ログ（例:「1回表 佐藤 健太: 左安 … 1点!」といった、選手名を含む表示用の文言）
  • 打席イベントの構造化データ（イニング、打順、打席結果、走者の進塁）

送信される情報は上記がすべてです。写真、位置情報、連絡先などが送信されることはありません。通信はすべて暗号化（HTTPS / TLS）されます。

共有されたこれらの情報は、共有を取り消すまで Supabase のサーバー上に保存されます。

03共有リンクの公開範囲と削除

スコアを共有すると、閲覧用の URL が発行されます。この URL には推測が困難な ID が含まれていますが、URL を知っている人であれば誰でも、共有されたスコアを閲覧できます。本アプリは、閲覧できる相手を限定する仕組み（パスワード、招待制など）を提供していません。

共有される内容には選手名が含まれるため、URL を渡す相手には十分ご注意ください。

共有したスコアは、アプリの「共有したスコア」画面からいつでも取り消せます。取り消すと、リンクを開いても内容は表示されなくなります。

取り消すための鍵は、共有した端末の中にのみ保存されます。機種変更やアプリの削除などで端末内の控えが失われた場合、アプリからは取り消せません。その場合はサポートページのお問い合わせフォームからご連絡ください。

04クラッシュログと動作速度の計測

本アプリは、アプリの不具合の検出と修正、および動作の改善（品質改善・分析目的）のため、Sentry を通じて以下の診断情報を収集します。

  • クラッシュ・エラーの情報: クラッシュやエラーが発生した際のエラー情報、端末の機種、OS のバージョン、アプリのバージョンなど、Sentry が自動的に収集する診断情報。
  • 動作速度の計測データ: アプリの起動や通信にかかった時間、画面の描画の滞りなど、動作の速さに関する計測データ。すべての計測を送るのではなく、約2割を無作為に選んで送信します。

Sentry は、個人を特定できる情報を送らない設定で利用しています。利用者が入力した試合データや選手名を意図的に送信する実装も行っていません。収集した診断情報を第三者へ販売したり、広告目的で提供したりすることはありません。

05フィードバックの送信時に送信される情報

本アプリの「設定・サポート」画面からは、ご意見・不具合の報告・ご質問・データ削除のご依頼を当団体へ送ることができます。送信ボタンを押したときにだけ、以下の情報が送信されます。

  • ご記入いただいた内容: 種類（ご意見 / 不具合 / 質問 / データ削除の依頼）と本文
  • 返信用のメールアドレス（任意）: 入力した場合にのみ送信されます。返信のためにのみ使用します。
  • アプリと端末の情報: アプリ名、アプリのバージョン・ビルド番号・runtimeVersion、OS（iOS / Android）と OS のバージョン、端末の言語設定、端末の機種名

アプリと端末の情報は、不具合を調査するために自動で添えられます。試合データ・チーム情報・共有したスコアが自動で添えられることはありません（本文に書かれた場合を除きます）。

送信された内容は、当団体が Cloudflare 上で運用する受付窓口（form.lh.tools）を経由して、当団体の Slack の非公開チャンネルに届きます。受信時には、受信日時、送信元の国（IP アドレスをもとに Cloudflare が判定したもの）、Cloudflare のリクエスト ID が添えられます。

送信元の IP アドレスは、短時間に続けて送信できる回数を制限する判定に使います。Slack に届く内容には含まれず、当団体が保存することもありません。

受け取った内容は、お問い合わせへの対応と、本アプリの不具合の調査・改善のためにのみ利用し、対応に必要な期間保管します。第三者へ販売したり、広告目的で提供したりすることはありません。なお、ウェブサイトのお問い合わせフォームでの取り扱いは、Life Hack Tools 共通のプライバシーポリシーをご覧ください。

06収集しない情報

本アプリは、以下の情報を収集しません。

  • 氏名、電話番号などの個人を特定できる情報（メールアドレスは、フィードバックの返信先としてご自身で入力した場合にのみ受け取ります）
  • 写真・カメラの映像
  • 位置情報
  • 連絡先（アドレス帳）

また、本アプリは広告を表示せず、広告目的のトラッキングも行いません。当団体が利用者の情報を第三者へ販売・共有することはありません。

07第三者サービスの利用

本アプリは、機能の提供のために以下の外部サービスを利用します。各サービスの取り扱いは、それぞれの提供者のプライバシーポリシーに従います。

  • Supabase: スコア共有機能（共有データの保存、閲覧用 URL の発行）にのみ利用します。データの同期やバックアップの用途では使用していません。
  • Sentry: クラッシュ解析と動作速度の計測（品質改善・分析目的）のため、診断情報の収集に利用します。
  • Cloudflare: フィードバックの受付窓口（form.lh.tools）の運用に利用します。
  • Slack: 受け付けたフィードバックを、当団体の非公開チャンネルで受け取るために利用します。

利用者が「スコアを共有」を実行しない限り、試合データやチーム情報が外部へ送信されることはありません（書き出しを選んだ場合は、ファイルを利用者が選んだ先に渡すのみで、当団体のサーバーへは送信しません）。

08権限

本アプリは、カメラ、写真ライブラリ、位置情報、連絡先などの機微な端末権限を必要としません。

09データの保存と削除

  • 端末内のデータ（試合・チーム情報）: 本アプリを端末からアンインストールすることで削除されます。
  • 共有したスコア: 共有を取り消すまで Supabase のサーバーに保存されます。アプリの「共有したスコア」画面から取り消すと、サーバーから削除されます。端末内の控えが失われて取り消せない場合は、下記のお問い合わせフォームよりご連絡ください。
  • クラッシュログ・動作速度の計測データ: Sentry のサービス上に保存されます。
  • フィードバック: 当団体の Slack の非公開チャンネルに保存され、対応に必要な期間保管します。

10お子様のプライバシー

本アプリは 18 歳以上の方を対象としており、お子様を対象としていません。当団体が意図的にお子様の個人情報を収集することはありません。

11ポリシーの変更

当団体は、必要に応じて本ポリシーを変更することがあります。変更があった場合は、本ページにて公開します。
